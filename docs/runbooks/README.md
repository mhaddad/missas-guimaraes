# Runbooks

Procedimentos de operação, escritos para quem não programa. A completar ao longo dos episódios:

- `restaurar-versao.md` — voltar a uma versão anterior dos dados de uma entidade (E4)
- `gerir-acessos.md` — dar, suspender e retirar acesso ao painel (E3)
- `pedido-em-conflito.md` — o que fazer quando um pedido fica em CONFLITO ou ERRO (E5)
- `migrar-para-producao.md` — passagem da homologação para as contas do Arciprestado (E7)
